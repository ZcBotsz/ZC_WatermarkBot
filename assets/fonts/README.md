# Fonts

All bundled fonts are licensed under the SIL Open Font License 1.1 (free for commercial use, may be redistributed with the bot):
Poppins, Montserrat, Roboto, Noto Sans (+ Arabic, Bengali, Devanagari, Gujarati, Gurmukhi, Kannada, Malayalam, Tamil, Telugu), Anton, Bebas Neue, Orbitron, Pacifico.

**Add your own font:** drop any `.ttf`/`.otf` file into `data/fonts/` (or this folder) and restart — it appears in the font picker (marked ★). Files in `data/fonts/` are the ones that survive Docker updates.
For colour emoji in watermarks install a system *Noto Color Emoji* font (the Docker image already does).
